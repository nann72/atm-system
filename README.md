# Система Банкомату (Варіант 1)

Проєкт реалізує модель банкомату з підтримкою:
- Зняття готівки (з власних, кредитних карток та карток інших банків)
- Розрахунку комісій
- Перегляду балансу та перевірки пін-коду
- Заправки готівкою (управління купюрами в касетах)
- Обробки виняткових ситуацій (нестача коштів, помилки пін-коду, порожній диспенсер)
